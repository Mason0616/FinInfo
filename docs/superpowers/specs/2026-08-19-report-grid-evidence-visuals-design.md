# 公开报告 2×2 证据图形设计

## 目标

公开报告首屏使用完整的 2×2 研究卡片网格，消除卡片内部与网格下方的空白，同时不伪装静态演示数据为真实市场数据。

## 卡片结构

桌面端每页四份报告，以两列两行排列。报告卡片与网格行共同拉伸，填满标题区与底部分页之间的剩余可视高度。每张卡片上半部保留主题、标题、结论与来源信息；下半部新增一张与报告主题对应的内联 SVG “示意趋势图”。

四种图形分别为：铜价与库存的双趋势线、GPU 推理成本的下降曲线、固态电池的阶段路径、跨境电商的履约成本分解。图形仅表达阅读结构，使用卡片内的 `DEMO TREND` 标签和“静态演示，不构成数据引用”说明，不出现真实价格、百分比或未经来源核验的数值。

SVG 直接在 React 组件中定义，不请求图片服务，不截取第三方报告，避免版权、许可与归因问题。未来接入可核验数据时，可将每份报告的图形替换为带来源、统计时间与原始链接的真实图表。

## 行为与响应式

分页维持每页四份、固定在内容区底部。桌面端图形随卡片高度伸展但保持图例可见；窄桌面与手机端仍使用一列卡片布局，不强制 2×2，以保证触控与阅读。

## 测试

浏览器测试确认首屏四张卡片均含带名称的演示图形、卡片网格覆盖分页上方的主要可用高度、分页仍在底部。测试不将图形当作真实数据源。
